# Rent4Less — رِنت فور لِس

منصة سعودية (نسخة تجريبية) لاستئجار القطع الفاخرة — حقائب، أحذية، ساعات، مجوهرات، إكسسوارات — باشتراك شهري. الموقع باللغة العربية (RTL) بالكامل، بلا أي أدوات بناء: HTML + CSS + JavaScript فقط.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`. (أو افتح `index.html` مباشرة في المتصفح.)

البيانات التجريبية تُحفظ في `localStorage` في المتصفح، فكل ما تفعله (استئجار، إضافة قطعة، موافقة…) يبقى بين الجلسات. لإعادة التعيين: لوحة المدير ← الإعدادات ← إعادة تعيين البيانات التجريبية.

## مفاتيح الوصول التجريبية

| المفتاح | الاسم | الدور | ماذا تجرّب |
|---|---|---|---|
| `ADMIN-2026` | عبدالله الحربي | مدير النظام | لوحة القيادة (MRR، الاشتراكات، نسبة التشغيل)، موافقات القطع، الطلبات، المستخدمون، اعتماد التحويلات، إعدادات العمولة |
| `OPS-5510` | سارة القحطاني | فريق العمليات | توثيق القطع، تحريك الشحنات عبر مراحلها (تجهيز ← شحن ← تسليم ← إرجاع ← تنظيف ← إتاحة) |
| `OWNER-7741` | نورة العتيبي | مالكة قطع (Consigner) | ٩ قطع، رصيد قابل للتحويل، إضافة قطعة جديدة، طلب تحويل بنكي |
| `OWNER-8852` | ريم الشمري | مالكة قطع | قطعة قيد التوثيق وأخرى مرفوضة بسبب |
| `RENTER-3320` | لمى الدوسري | مشتركة — باقة ماس | قطعتان معها الآن وخانة ثالثة فارغة: جرّبي الاستئجار والإرجاع والتمديد |
| `RENTER-4410` | هند المطيري | مشتركة — بلا باقة | تجربة الاشتراك من الصفر |
| `RENTER-5566` | منيرة الزهراني | مشتركة — باقة لؤلؤة | طلب في الطريق، وحدود الفئة (لا تصل لقطع ذهب/ماس) |

## نموذج العمل

**المشتركة (Renter)** تدفع اشتراكاً شهرياً ثابتاً حسب الباقة، وتختار القطع ضمن "خانات" باقتها:

| الباقة | السعر / شهر | قطع في نفس الوقت | تبديلات | الوصول |
|---|---|---|---|---|
| لؤلؤة | 499 ر.س | 1 | 1 | فئة لؤلؤة (قطع حتى ~10 آلاف) |
| ذهب | 999 ر.س | 2 | 3 | لؤلؤة + ذهب (10–30 ألف) |
| ماس | 1,999 ر.س | 3 | غير محدود | كل القطع بما فيها النادرة + مستشارة أناقة + توصيل نفس اليوم |

**المالكة (Consigner)** تسجّل قطعتها، والمنصة تتكفّل بالاستلام والتوثيق والتصوير والتخزين والتنظيف والتأمين. لكل قطعة "قيمة إيجار شهرية مرجعية" (~4٪ من قيمتها السوقية). عند كل إيجار تحصل المالكة على حصتها (افتراضياً 60٪ من القيمة المرجعية — قابلة للتعديل من إعدادات المدير) وتطلب التحويل متى بلغ رصيدها 100 ر.س.

**المنصة** تحقق هامشها من الفرق بين إيرادات الاشتراكات ومدفوعات المالكات وتكاليف التشغيل (توصيل، تنظيف، تأمين).

### دورة حياة القطعة
`بانتظار المراجعة` (المدير) → `قيد التوثيق` (العمليات) → `متاحة` → `مؤجّرة` → `تنظيف وتعقيم` → `متاحة` … أو `مرفوضة` / `مسحوبة` من المالكة.

### دورة حياة الطلب
`قيد التجهيز` → `في الطريق` → `معكِ الآن` → `طلب إرجاع` → `تم الاستلام` → `تنظيف وتعقيم` → `مكتمل`

## التأثيرات البصرية
مؤشر مخصص بحلقة متأخرة، توهج ذهبي يتبع الماوس، إضاءة موضعية وحدود مضيئة على البطاقات، إمالة ثلاثية الأبعاد، بارالاكس للهيرو والكرات الخلفية، أزرار مغناطيسية، ظهور عند التمرير، عدّادات متحركة، ولمعان يمر على الصور. كل التأثيرات تتعطل تلقائياً على شاشات اللمس ومع `prefers-reduced-motion`.

## البنية
```
index.html        الهيكل، شريط التنقل، التذييل
css/style.css     التصميم (متغيرات، بطاقات، لوحات، استجابة)
js/data.js        البيانات التجريبية والثوابت (الأدوار، الحالات، الباقات، القطع…)
js/store.js       الحالة والإجراءات لكل دور + حفظ localStorage
js/views.js       صفحات الموقع ولوحات الأدوار الأربعة (HTML كنصوص)
js/effects.js     المؤشر والإضاءة والإمالة والبارالاكس
js/app.js         التوجيه (hash routing)، الأحداث، الإشعارات، النوافذ
```
